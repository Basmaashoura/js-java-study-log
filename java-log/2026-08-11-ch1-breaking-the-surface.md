# Head First Java — Ch.1: Breaking the Surface

**Date:** 2026-08-11

## Key concepts

- Compiler (`javac`) turns source (`.java`) into platform-independent bytecode (`.class`); JVM runs the bytecode
- Code nesting: source file → class → methods → statements
- Every app needs one `main()` method: `public static void main(String[] args)`
- Three things you can do in a method: statements, loops (`while`, `for`), branching (`if`/`else`)
- `=` is assignment, `==` is comparison
- `print` stays on the same line, `println` adds a newline
- Java is strongly typed — can't test a non-boolean directly in `if`/`while`
