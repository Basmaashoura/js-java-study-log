# Head First Java — Ch.2: A Trip to Objectville

**Date:** 2026-08-14

## Key concepts

- OO lets you extend a program without touching tested, working code (Chair Wars story)
- Class = blueprint, object = instance made from it (recipe vs. cookies)
- Instance variables = what an object knows (state); methods = what an object does (behavior)
- `new ClassName()` creates an object on the heap; dot operator (`.`) accesses its variables/methods
- Two-class pattern: real class + `<ClassName>TestDrive` class with `main()`
- Inheritance: superclass holds shared code, subclasses inherit it automatically
- Overriding: a subclass redefines an inherited method to customize behavior
- A real Java app is objects talking to objects, not one big `main()`
- Garbage collection: objects live on the heap; JVM reclaims memory once an object is unreachable
