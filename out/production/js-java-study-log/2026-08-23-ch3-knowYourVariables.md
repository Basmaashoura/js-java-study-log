# Head First Java — Ch.3: Know your variables

**Date:** 2026-08-23

## Key concepts

- Two variable flavors: primitive vs. reference — the "cup" and "remote control" analogies 
- Declaration rules: every variable needs a type and a name 
- The eight primitive types, their bit depths/ranges, and the mnemonic (Be Careful! Bears Shouldn't Ingest Large Furry Dogs)
- Spillage / implicit widening — why byte b = intVariable; won't compile even for small values 
- Literal suffixes (L for long, f for float)
- Naming rules and reserved words 
- Object references as "remote controls" — the 3 steps of declare/create/link 
- null references and eligibility for garbage collection 
- Reference reassignment (b = c;) — copies the reference, not the object; effect on heap reachability 
- Arrays are always objects, even when holding primitives; array elements as reference variables (Dog array = array of Dog remote controls, not Dog objects)
