# Eloquent JavaScript — Ch.5: Higher-Order Functions

**Date:** 2026-09-26

## Key concepts

- Higher-Order Functions are functions that operate on other functions.
- Functions as "gaps" filled by passing other functions in: `repeat(n, action)`, `forEach`
- `filter` (keep matching elements), `map` (transform each), `reduce` (fold to one value) — traced each by hand
- `some` (like `||` across an array) vs. `every` (like `&&`)
- `find` returns the first match or `undefined`
- Composability: chaining `filter`/`map`/`reduce` trades some speed for readability
- UTF-16 gotcha: `.length` and `str[i]` count code units, not characters; `for...of` gives real characters
- `countBy` + `characterScript` walked through the `textScripts` capstone example stage by stage
